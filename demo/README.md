# demo

Ajanın koruma **açık** ve **kapalı** hâlini karşılaştıran Streamlit arayüzü.

- `demo_ajan.py`: komut satırında çalışan ilk prototip

Sorumlu: Azra Aslan

## Prototipi çalıştırma

```bash
pip install openai
export API_KEY="..."
export BASE_URL="https://api.groq.com/openai/v1"
export MODEL="openai/gpt-oss-20b"
python demo/demo_ajan.py
```

API anahtarınızı asla bu depoya yüklemeyin.
